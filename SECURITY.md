# Security Policy

## Supported versions

Only the latest `main` and the most recent release tag receive security fixes.

| Version | Supported |
|---|---|
| latest main | yes |
| latest tag  | yes |
| older tags  | no |

## Reporting a vulnerability

Email security issues to `security@studiocentos.com`, or open a *private*
security advisory via the GitHub Security tab. **Do not open a public issue for
a vulnerability.** Include the affected crate or adapter, the game you were
running, and a minimal reproduction if you have one.

This is a spare-time fork of a larger project, so there is no response SLA —
please allow a few days before following up. Advisories stay private until a fix
is available.

## Scope

game-rl is developer tooling that turns games into multi-agent environments
(Rust workspace, .NET/Harmony bridge for RimWorld, Lua mods for Project Zomboid
and Factorio). Its security surface:

- **The MCP server and its transports.** `game-rl-server` listens on a Unix
  socket and a file-based IPC path, and speaks MCP to agents such as Claude
  Code. Anything on the same machine that can open those endpoints is trusted
  code — an issue there is privilege confusion between the game, the bridge and
  the agent.
- **Shared-memory vision streams.** Zero-copy frame buffers are a native
  code path: races, size mismatches or wrong permissions can crash the server
  or leak frames from another process.
- **Game-supplied input reaching an LLM.** Observations and rewards are
  generated by game state, save files and third-party mods. Untrusted game data
  that reaches a language model is a prompt-injection surface; the server should
  treat it as data, never as instructions.
- **Malicious adapters.** Adapter binaries and Lua/C# mods are loaded into
  games and execute game-side. Users should only install adapters they trust;
  a compromised adapter is a compromised host.
- **CI and build.** The workflows build native libraries and publish release
  binaries for all three games — a poisoned dependency would reach real
  players.

Out of scope: game behaviour, balance, or RL training quality. Bugs that only
degrade simulation quality belong in the issue tracker.
